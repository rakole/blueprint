# Command Family Guides

These files summarize Blueprint command families for coding agents. They are not
user tutorials. Use them to find the likely source surfaces, high-risk gates,
and focused verification for a change.

For every family:

- Keep follow-up routing inside the implemented command surface.
- Keep command manifests thin and skill-led.
- Use MCP tools for state.
- Update command, skill, runtime metadata, and tests together when changing
  availability or behavior.

Families:

- `foundation.md`
- `lifecycle.md`
- `roadmap-and-milestones.md`
- `capture-and-lightweight-execution.md`
- `review-quality-and-shipping.md`
- `workspace-and-maintenance.md`
