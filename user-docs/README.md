# Blueprint User Docs

Blueprint helps you turn repo work into visible, phase-based delivery. It maps an existing codebase or bootstraps a new project, keeps plans and evidence in validated project state, and routes you toward the next safe command instead of asking you to remember the workflow.

## First Safe Command

Start with:

```text
/blu-help
```

`/blu-help` is read-only. It checks project readiness and the implemented command catalog, then suggests safe next steps for the repo you are in.

## What Blueprint Promises

- A clear path from idea to shipped change.
- Project state that survives across chat sessions.
- Plans, research, reviews, and verification evidence written through Blueprint tools instead of manual file edits.
- Router guidance that should recommend only runnable Blueprint commands.
- Explicit confirmation before high-risk operations such as shipping, undo, cleanup, workspace removal, or patch replay.
